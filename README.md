# LADON Launcher releases

Release APKs and signed update feeds for LADON Launcher. The launcher source code is private and is not published in this repository.

## Updating LADON

Open **Settings → Backup & about → Software Update** in an updater-enabled LADON build. Choose **Beta** for preview releases or **Stable** for recommended releases. Updates download automatically when the connection and head unit allow. Choose **Install Update** whenever you are ready and confirm with Android.

Automatic checks stay on. Checks wait for a quiet moment; downloads additionally require an unmetered internet connection. Transfers pause during demanding launcher activity, heat, low memory, power saving or map downloads, and resume after conditions settle. Installation always stays under your control. You can pause the current download or delete a saved update.

The updater verifies the signed release information, APK checksum, app identity, architecture and signing certificate before opening Android’s installer.

For an initial installation, download the APK matching your head unit’s architecture from the Releases page. Keep your existing LADON installation when updating so its configuration is retained.

The `updates` release contains small signed channel feeds. Versioned releases contain the APKs and release notes.
